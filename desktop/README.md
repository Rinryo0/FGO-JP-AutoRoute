# FGO-JP-AutoRoute — Windows 原生桌面版\n\n## v0.5.0 功能\n\n- Windows 原生視窗，不會開啟瀏覽器。\n- MuMu Player 12 ADB 連線，可自動掃描常用連接埠或手動輸入 `127.0.0.1:16416`。\n- 連線後自動開啟 scrcpy 即時鏡像視窗（最高設定 60 FPS），另保留 ADB 畫面預覽。\n- 倫敦第四特異點第六節範例路線：章節 → 地圖節點 → 任務列 → 支援從者 → 隊伍開始。\n- 自動略過劇情（可關閉）。\n- 戰鬥自動按 Attack，辨識指令卡畫面後選擇前三張卡。\n- 自動處理 Master EXP 與戰利品結算；依倫敦任務列五格進度計算完成次數。\n- 暫停、繼續、停止；程式視窗在前景時可按 `F8` 緊急停止。\n- 第一次使用有逐步模板擷取精靈，不必編輯 JSON。\n- AP 不足或遇到未辨識畫面時會停止；不會使用聖晶石或蘋果恢復 AP。\n\n## 第一次使用\n\n1. 開啟 MuMu 12 與日版 FGO，將模擬器固定為橫向 16:9，建議 1280×720。\n2. 執行 `FGO-JP-AutoRoute.exe`，按「連接 MuMu」。ADB 位址可先用 `auto`，也可輸入 `127.0.0.1:16416`；連線後會自動開啟 scrcpy 即時鏡像視窗。\n3. 按「設定畫面模板」。依照精靈提示，在遊戲中切換到對應畫面，拖曳框選按鈕或標題，按「儲存並下一個」。\n4. 必要模板都完成後，按「檢查設定」。\n5. 設定目標進度及最多戰鬥次數，按「開始自動推關」。第一次請全程監看。\n6. 隨時按「停止」或 `F8` 中止。\n\n模板是從使用者自己的 MuMu 畫面擷取，保存在 `%LOCALAPPDATA%\\FGO-JP-AutoRoute\\templates`，不會上傳到 GitHub。\n\n## 目前支援範圍\n\n目前內建路線是依使用者提供的畫面設定：**第一部／第四特異點 倫敦／第六節「ロンドン・ナイト」**。其他章節需要新增對應的路線與畫面模板，不能直接套用這條路線。\n\n戰鬥規則是基礎策略：按 Attack，選擇前三張指令卡。它不會判斷敵人職階、卡牌傷害、技能冷卻或寶具最佳時機，因此不能保證所有戰鬥都能勝利。特殊戰鬥請先人工確認。\n\n程式不會自動購買道具或恢復 AP。遇到 AP 恢復視窗或其他未設定視窗時，會因找不到可辨識畫面而安全停止。\n\n## 原始碼與建置\n\n原生視窗程式碼放在 `main.py.xz.b64`，自動化引擎由既有來源包還原。GitHub Actions 會先解壓縮原始碼，再於雲端 Windows 編譯機使用 Python 3.11 建置單檔 EXE。使用者電腦不需要安裝 Python。\n\n`scrcpy` 使用官方 Windows 發行版，版本 v5.0.1；其授權文件會隨下載 ZIP 一起提供。\n\n## 注意\n\n本專案使用本機 MuMu ADB 螢幕擷取與觸控輸入，不使用 ROOT、不讀取遊戲記憶體、不修改遊戲資料或封包。遊戲自動化可能涉及遊戲服務條款及帳號風險，請自行確認。請勿無人監控長時間執行。\n
