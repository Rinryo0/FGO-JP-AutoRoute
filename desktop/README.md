# FGO-JP-AutoRoute v0.6.0-dev

## 目標規格

- Windows 11 原生視窗 EXE
- MuMu Player 12 / 日版 FGO
- 1280×720
- ADB 連線、scrcpy 即時鏡像
- 穩定優先；未驗證畫面一律停止
- 第一部九章節目錄先完成，路線逐關驗證後才開放

## 本分支基礎功能

- 分頁式控制中心：總覽、章節與路線、戰鬥策略、支援偏好、素材與 AP、戰鬥統計、系統設定。
- 保留既有倫敦第四特異點第六節自動化引擎及模板擷取精靈。
- 第一部章節目錄完整列出九個主要章節；只有倫敦第六節目前連接既有引擎。
- 自訂路線可建立與保存，但不會執行未驗證的路線。
- AP 預算以手動輸入的 AP 和關卡消耗估算；開始任務時可限制最大戰鬥次數。
- 戰鬥工作階段與手動確認的素材掉落保存到本機 SQLite。
- 可保存支援從者及概念禮裝偏好。
- 統計可匯出 CSV。
- F8 緊急停止；不自動使用聖晶石、金蘋果、銀蘋果或銅蘋果。

## 建置

GitHub Actions 會在 Windows 雲端建置機使用 Python 3.11 編譯單檔 EXE。玩家電腦不需要安裝 Python。建置會從保留的 v0.5 壓縮原始碼還原 legacy_main.py，並從既有來源包還原 fgoauto 引擎。
