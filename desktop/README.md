# FGO-JP-AutoRoute v0.6.0-dev

## 目標規格

- Windows 11 原生視窗 EXE
- MuMu Player 12 / 日版 FGO
- 1280×720
- ADB 連線、scrcpy 即時鏡像
- 日文 OCR 自動畫面辨識，不要求手動設定模板
- 穩定優先；未知或低信心畫面一律保持待命

## 本分支基礎功能

- 分頁式控制中心：總覽、章節與路線、戰鬥策略、支援偏好、素材與 AP、戰鬥統計、系統設定。
- RapidOCR + ONNX Runtime 日文 OCR，嘗試辨識主畫面、章節地圖、關卡清單、支援選擇、隊伍確認、劇情、戰鬥指令、指令卡與結算畫面。
- 連接 MuMu 後自動持續辨識，不需要使用者擷取 13 張模板。
- 第一部章節目錄完整列出九個主要章節。
- 自訂路線可建立與保存，但不會執行未驗證的路線。
- AP 預算以手動輸入的 AP 和關卡消耗估算。
- 戰鬥工作階段與手動確認的素材掉落保存到本機 SQLite。
- 可保存支援從者及概念禮裝偏好。
- 統計可匯出 CSV。
- F8 緊急停止；不自動使用聖晶石、金蘋果、銀蘋果或銅蘋果。

## 尚未開放

- 自動選章、選關、支援從者／禮裝自動篩選。
- 自動戰鬥點擊、技能與寶具決策、結算後自動循環。
- AP 數字與素材掉落自動 OCR。
- 第一部九章的逐關路線執行。

目前 OCR 是畫面分類原型，需逐一以實際 MuMu 遊戲畫面驗證。辨識不到或低信心時會保持待命；自動推關按鈕在完成路線執行整合前保持停用。舊倫敦引擎僅保留作相容參考，不再啟動手動模板精靈。

## 建置

GitHub Actions 會在 Windows 雲端建置機使用 Python 3.11 編譯單檔 EXE，並將 RapidOCR、ONNX Runtime 及日文 OCR 模型一併封裝。玩家電腦不需要安裝 Python。
