# FGO-JP-AutoRoute v0.7.0-dev

## 目標環境

- Windows 11 原生視窗 EXE
- MuMu Player 12 / 日版 FGO
- 1280×720
- ADB + scrcpy
- 日文 OCR 自動辨識，不需手動模板
- 主線推進與素材循環兩種任務模式

## v0.7.0 開發內容

- automation.py：主線／素材任務狀態機、OCR 動態目標點擊、AP 不足停止、結算循環、逾時停止、未知畫面診斷。
- vision.py：RapidOCR 文字辨識及每個文字的即時 bounding box。
- battle.py：OpenCV 即時指令卡顏色／輪廓偵測，辨識不到三張卡即停止。
- adb_control.py：MuMu ADB 點擊與滑動。
- scheduler.py：本機每日排程。
- analytics.py：每小時場次、AP 效率、目標素材進度。
- storage.py：SQLite 工作階段、戰鬥、AP 與素材紀錄。
- backup.py：JSON 設定備份與還原。
- 原生 UI：主線／素材模式、關卡名稱、每日排程、設定備份、開始／停止任務。
- F8 緊急停止；不自動使用聖晶石或蘋果。

## 使用流程

1. 啟動 MuMu 12 與日版 FGO，保持遊戲在前景。
2. 啟動 EXE，連接 MuMu ADB。
3. 選擇「主線推進」或「素材刷取」。
4. 素材模式需輸入遊戲畫面顯示的日文關卡名稱、目標素材及目標數量。
5. 設定最大戰鬥次數及每場 AP 消耗，確認遊戲目前畫面可辨識後開始。
6. 全程監看；按 F8 可立即停止。

## 實機驗證狀態

這是自動化開發版，不是已對所有帳號、章節、隊伍、關卡與遊戲更新完成驗證的正式全自動工具。OCR 文字框與 CV 卡片位置採動態偵測，但仍需實機驗證。找不到目標、未知畫面、AP 恢復提示或畫面長時間不變時會停止。

技能圖示及寶具使用時機尚未有通用可靠辨識器，預設不自動使用技能或寶具。請勿把這個版本當作無人監看的全章節保證通關工具。

遊戲自動化可能涉及遊戲服務條款及帳號風險，請自行確認。
