# FGO-JP-AutoRoute

**Windows 11 · MuMu Player 12 · 日版 FGO**

## v0.5.0 — Windows 原生自動推關版

這次將原本只有畫面監看的 Windows 視窗，升級為包含視覺路線與基礎戰鬥自動化的桌面程式。

### 功能

- Windows 原生視窗與 MuMu ADB 連線。
- 連線後自動開啟 scrcpy 即時鏡像視窗（最高設定 60 FPS），並保留 ADB 畫面預覽。
- 倫敦第四特異點第六節路線：章節、地圖節點、任務列、支援從者、隊伍開始。
- 自動略過劇情（可選）。
- 自動按 Attack，辨識指令卡選擇畫面後選前三張卡。
- 自動處理 Master EXP 與戰利品結算。
- 讀取倫敦任務列五格進度，達到設定目標後停止。
- 暫停、繼續、停止及 F8 緊急停止。
- 一次性畫面模板設定精靈，不需要編輯 JSON。
- 不會自動使用聖晶石或蘋果恢復 AP；遇到未知畫面會停止。

### 下載 EXE

1. 開啟本 Repository 的 Actions。
2. 選擇最新的 Build Windows Desktop EXE。
3. 等待工作顯示綠色成功。
4. 在 Artifacts 下載 FGO-JP-AutoRoute-Windows-x64。
5. 解壓縮後執行 FGO-JP-AutoRoute.exe。

Python 只會在 GitHub 雲端 Windows 編譯機使用，不需要安裝在你的電腦。

### 第一次使用

1. 開啟 MuMu 12 與日版 FGO，建議固定橫向 1280×720。
2. 執行 EXE，按「連接 MuMu」。ADB 位址可先用 auto，也可輸入 127.0.0.1:16416；連線後會自動開啟 scrcpy 即時鏡像視窗。
3. 按「設定畫面模板」，依序切換到遊戲中的章節、地圖、關卡、支援、隊伍、劇情、戰鬥及結算畫面，拖曳框選精靈提示的按鈕或標題。
4. 按「檢查設定」，確認必要模板已完成。
5. 設定進度目標及最多戰鬥次數，按「開始自動推關」。第一次請全程監看。
6. 按 F8 或「停止」可緊急中止。

### 目前支援範圍

目前內建範例路線為**第一部／第四特異點 倫敦／第六節「ロンドン・ナイト」**，依使用者提供的日版畫面設計。其他章節需要新增各自的路線與模板。

戰鬥目前採用基礎策略：按 Attack，選前三張指令卡；尚未加入敵方職階分析、技能／寶具決策或高效率配卡，特殊戰鬥請先人工確認。

### 使用者模板與設定

畫面模板和進度設定保存在 %LOCALAPPDATA%\FGO-JP-AutoRoute，不會上傳到 GitHub。每台模擬器的 UI 縮放或解析度不同，可能需要重新擷取模板。

### 原始碼

原生視窗程式碼放在 desktop/main.py.xz.b64，自動化引擎與測試由既有 FGO-JP-AutoRoute-v0.3.0-source.zip 還原。GitHub Actions 會在建置前解壓縮，再編譯 Windows EXE。

### 安全與限制

- 只連線本機 MuMu ADB，不使用 ROOT、不讀取遊戲記憶體、不修改遊戲資料或封包。
- 不會購買道具或使用聖晶石／蘋果恢復 AP。
- 找不到可辨識畫面、AP 不足或戰鬥逾時會安全停止。
- 遊戲自動化可能涉及服務條款及帳號風險；請自行確認，不建議無人監控長時間執行。
