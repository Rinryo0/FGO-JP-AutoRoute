# FGO-JP-AutoRoute

Windows 11 · MuMu Player 12 · 日版 FGO · 1280×720

## v0.6.0-dev — 自動畫面辨識開發版

這個分支正在把舊版「手動擷取 13 個畫面模板」改為日文 OCR 自動判斷畫面。連接 MuMu 後，程式會持續擷取遊戲畫面，並嘗試辨識主畫面、章節地圖、關卡清單、支援選擇、隊伍確認、劇情、戰鬥指令、指令卡與結算畫面。

### 本分支已加入

- Windows 原生 Tkinter 控制中心與分頁 UI。
- MuMu ADB 連線、程式內畫面預覽，以及 scrcpy 即時鏡像。
- 日文 OCR（RapidOCR + ONNX Runtime），不需要使用者設定或擷取畫面模板。
- 自動畫面狀態判斷；無法辨識時保持待命，不會猜測或亂點。
- 第一部九個章節的路線目錄。
- 自訂路線資料可儲存，但未驗證路線不會執行。
- AP 預算手動估算、本機 SQLite 工作階段與素材紀錄、CSV 匯出。
- 支援從者／禮裝偏好保存。
- 設定保存在 %LOCALAPPDATA%/FGO-JP-AutoRoute，不會上傳到 GitHub。
- F8 緊急停止；不會自動使用聖晶石或任何蘋果恢復 AP。

### 重要限制

- 這是 OCR 畫面辨識原型，仍需使用實際 MuMu 畫面逐一驗證辨識率。
- 本版尚未開放自動選章、選關、支援從者點選、自動戰鬥或自動結算操作；控制中心會明確顯示「自動推關（尚未開放）」。
- 第一部九章目前是章節目錄，不代表九章都有可執行路線。
- AP 數字、素材掉落、支援從者與禮裝仍未自動讀取／篩選。
- 技能、寶具與指令卡決策尚未接入。
- 舊倫敦路線引擎保留作相容參考，但本版不再要求或呼叫手動模板精靈。

### 下載 Windows EXE

前往 GitHub Actions 的 Build Windows Desktop EXE 工作流程，下載 FGO-JP-AutoRoute-Windows-x64 Artifact。Python 只在 GitHub 雲端建置機使用，玩家電腦不需要安裝 Python。

### 開發原則

1. 不要求玩家手動擷取畫面模板；優先採用日文 OCR 與畫面狀態辨識。
2. 只有經實機驗證的畫面狀態與路線才會開放自動操作。
3. 未知畫面、低辨識信心、AP 不足或流程不符時停止，不猜測下一步。
4. 不讀取遊戲記憶體、不修改遊戲資料或封包。
5. AP 恢復、付費資源及任何消耗蘋果的操作保留人工確認。

遊戲自動化可能涉及遊戲服務條款及帳號風險，請先自行確認並全程監看。
