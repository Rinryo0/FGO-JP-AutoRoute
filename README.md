# FGO-JP-AutoRoute

Windows 11 · MuMu Player 12 · 日版 FGO

## v0.6.0-dev — 模組化控制中心開發版

本分支依照 1280×720、穩定優先戰鬥策略，先整理第一部章節目錄與桌面程式架構，再逐步驗證各章節路線。

### 本分支已加入的基礎功能

- Windows 原生 Tkinter 控制中心與分頁式 UI。
- MuMu ADB 連線、程式內畫面預覽，以及 scrcpy 即時鏡像。
- 第一部九個章節的路線目錄。
- 保留既有第四特異點倫敦第六節路線引擎與畫面模板精靈。
- 自訂路線資料可儲存；未驗證路線不會自動執行。
- AP 預算估算：由使用者手動輸入 AP 與關卡消耗，計算本次安全上限。
- 本機 SQLite 戰鬥工作階段紀錄、手動素材掉落紀錄與 CSV 匯出。
- 支援從者／禮裝偏好保存。
- 設定保存在 %LOCALAPPDATA%\\FGO-JP-AutoRoute，不會上傳到 GitHub。
- F8 緊急停止；不會自動使用聖晶石或任何蘋果恢復 AP。

### 目前尚未完成、不可宣稱已支援的功能

- 第一部除倫敦第六節範例外，其餘章節的自動路線仍待逐關建立與實機驗證。
- 支援從者偏好目前只保存設定；自動 OCR 篩選尚未接入。
- AP 目前是手動輸入估算，尚未自動讀取遊戲 AP。
- 素材掉落目前由使用者確認後登記，尚未自動辨識結算圖示。
- 技能、寶具與敵方職階判斷尚未自動執行；本分支採穩定優先，不會自行亂放技能或寶具。
- 目前戰鬥流程沿用既有倫敦路線引擎，並非所有關卡通用的智慧戰鬥 AI。

### 下載 Windows EXE

合併或推送後，前往 GitHub Actions 的 Build Windows Desktop EXE 工作流程，下載 FGO-JP-AutoRoute-Windows-x64 Artifact。Python 只在 GitHub 雲端建置機使用，玩家電腦不需要安裝 Python。

### 開發原則

1. 所有章節先列入目錄，但只有完成畫面模板、路線節點、任務進度與異常流程驗證的關卡才標示為可執行。
2. 先測試 ADB、畫面辨識、暫停與停止，再逐步開放自動點擊。
3. 不讀取遊戲記憶體、不修改遊戲資料或封包。
4. AP 恢復、付費資源及任何消耗蘋果的操作保留人工確認。
5. 遇到未知畫面、AP 不足或流程不符時停止，不猜測下一步。

遊戲自動化可能涉及遊戲服務條款及帳號風險，請先自行確認並全程監看。
