# FGO-JP-AutoRoute

Windows 11 · MuMu Player 12 · 日版 FGO · 1280×720

## v0.7.0-dev — 主線推進＋素材循環自動化開發版

本分支把原本只有 OCR 畫面分類的原型，擴充為以即時 OCR 文字框及 CV 指令卡辨識驅動的自動任務引擎，包含「主線推進」與「素材刷取」兩種模式。

### 已加入的程式模組

- Windows 原生 Tkinter 控制中心，沒有網頁控制介面。
- MuMu ADB 連線、scrcpy 即時鏡像、程式內畫面預覽。
- RapidOCR 日文辨識，保留即時文字框座標，讓操作依 OCR 找到的文字位置執行，不需手動建立 13 張模板。
- 自動任務引擎：主線／素材兩種模式、任務上限、狀態轉移、停止／暫停、操作去重及無進展逾時。
- 主線章節目錄與章節完成後的下一章切換邏輯。
- 素材任務可指定關卡、目標素材及目標數量；辨識到結算文字時登記掉落並依上限循環。
- 支援從者／禮裝偏好匹配；未設定偏好時採第一個可辨識候選項。
- 戰鬥操作：OCR 找到攻擊按鈕後點擊；OpenCV 依即時畫面顏色與輪廓找出三張指令卡，辨識不足時停止。
- AP OCR 解析、AP 不足停止，不自動使用金蘋果、銀蘋果、青銅蘋果或聖晶石。
- SQLite 工作階段、單場戰鬥、AP 消耗、素材掉落統計及 CSV 匯出。
- 每日排程、Windows 系統提示音、設定 JSON 備份／還原。
- 未知畫面診斷截圖保存在本機 LocalAppData 下的 FGO-JP-AutoRoute/diagnostics。
- F8 緊急停止。

### 重要：目前開發版的實際限制

此分支已加入可執行的自動化框架，但不能宣稱已完成所有 FGO 章節及所有戰鬥型態的實機驗證：

- 第一部九章的章節目錄與章節切換邏輯已加入；各章實際地圖、關卡節點與劇情流程仍需逐章用 MuMu 12 實機驗證。
- 素材模式依使用者輸入的關卡名稱與 OCR 結果尋找關卡；日文名稱辨識錯誤或關卡文字不在畫面時會等待逾時後停止。
- 指令卡辨識目前是顏色／輪廓 CV 原型；不同畫面特效、從者卡面、寶具卡與 UI 動畫仍需實機校準。
- 技能圖示與寶具可用時機尚未具備可靠的通用辨識器；預設不自動按技能或寶具，避免誤用。
- 素材掉落統計依結算頁 OCR 文字解析；遊戲文字未被 OCR 讀取時不會計入，應以實際掉落畫面驗證。
- OCR 的分類信心度是規則評分，不等於模型對每個操作目標的保證；操作後畫面沒有變化、找不到目標或 AP 恢復畫面都會停止。
- 遊戲自動化可能涉及遊戲服務條款與帳號風險，使用者需自行確認並監看。

### 安全邊界

- 不讀取或修改遊戲記憶體，不攔截或修改網路封包。
- 不自動使用任何 AP 恢復道具、聖晶石或付費資源。
- 不對未知畫面猜測座標；只使用 OCR 即時框或 CV 即時偵測座標。
- 任何辨識失敗或流程停滯均停止，等待使用者處理。

### 下載 Windows EXE

GitHub Actions 會在 Windows 雲端建置機使用 Python 3.11 編譯單檔 EXE；玩家電腦不需要安裝 Python。開發分支的建置完成後，請在該次 Actions 執行頁面下載 FGO-JP-AutoRoute-Windows-x64 Artifact。
